Connecter votre Google Drive

Renseignez le Client ID OAuth créé sur Google Cloud Console. Il est enregistré uniquement sur cet appareil.

—
  1. Créer un projet — sur console.cloud.google.com, nouveau projet.
  2. Activer l'API — API et services → Bibliothèque → « Google Drive API » → Activer.
  3. Écran de consentement OAuth — Externe, votre nom et email, ajoutez votre adresse en utilisateur test.
  4. Identifiants — Créer des identifiants → ID client OAuth → Application Web → collez l'origine ci-dessus dans « Origines JavaScript autorisées ».
  5. Copier le Client ID obtenu et le coller ci-dessus.
